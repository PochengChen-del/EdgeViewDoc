    Detailed Description

    提供清單彈出選擇，且可以同時選擇多個項目，並提供輸入文字篩選清單。

    此元件與其他 Form 元件提供一致的表單互動行為與樣式，並透過 wavalidator 提供驗證功能。

    元件內建互動狀態：

    • normal
    • hover
    • active
    • disable
    • readonly

    各狀態會繼承對應的 base state（例如 normal → normalbase）， 並透過 themeStyle 套用背景、邊框與內容顏色等。

    selectedStatus : var [read-only]

    選取狀態資訊（含全選 / 部分選取 / 分組統計）。

    回傳物件包含：

    • summary：整體選取狀態
    • match：目前搜尋結果中的選取狀態
    • sections：各分組選取狀態

    結構如下：

    {
    summary: { any, all, count, total },
    match: { any, all, count, total },
    sections: {
        [sectionName]: {
            any, all, count, total, index
        }
    }
}
    • any：是否至少選取一項
    • all：是否全部選取
    • count：選取數量
    • total：總數量
