    Detailed Description

    用於集中管理通知提示元件。

    負責處理通知佇列、顯示排序、自動位置調整與通知生命週期管理。

    當畫面空間不足時，新通知會暫存於佇列中，待空間可用後再顯示。

    支援功能：

    • 通知佇列管理（queue）
    • 通知堆疊顯示（notifications）
    • 自動位置排列
    • 通知自動建立與銷毀

    Method Documentation

    addNotify(var notifyData)

    加入通知至通知佇列。

    若通知空間足夠，會立即顯示通知。

    \paramnotifyData 通知資料物件。 結構：

    {
    notifyType,
    title,
    message,
    detail,
    interval
}

    real getRootHeight()

    取得通知可用區域高度。

    會優先使用 Global.root 高度， 若不存在則使用 parent 高度。

    \return可用高度。


    real getTotalNotificationHeight()

    取得目前所有通知總高度。

    包含通知間距與頂部間距。

    \return通知總高度。


    notify()

    顯示下一筆通知。

    若畫面空間不足，會延後重新檢查並等待顯示。


    onResized()

    重新排列所有通知位置。

    會依照通知高度重新計算 Y 座標。
