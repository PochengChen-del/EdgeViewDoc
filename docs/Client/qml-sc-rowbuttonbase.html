    Detailed Description

    RowButtonBase

    是 RowButton 的基礎。

    元件內建互動狀態：

    • normal
    • hover
    • active
    • disable

    各狀態會繼承對應的 base state（例如 normal → normalbase）， 並透過 themeStyle 套用背景、邊框與內容顏色等。
