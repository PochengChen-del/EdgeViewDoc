    Detailed Description

    提供搜尋目標選擇、條件輸入、分頁與結果列表功能。

    支援功能：

    • 類型處理與顯示（type）
    • 搜尋控制（search）
    • 分頁控制
    • 搜尋結果選取與提交

    Property Documentation

    actived : bool [read-only]

    是否為 active。


    addEnabled : bool

    是否允許新增項目。

    預設 true。


    currentPage : int [read-only]

    目前頁數。


    currentPrefix : string [read-only]

    目前搜尋結果使用的前綴字串。

    在 BI Tag 搜尋模式下，會自動組合 Group/Object 路徑。


    currentSearchObject : var [read-only]

    目前搜尋使用的 Object。


    currentSearchTarget : string [read-only]

    目前搜尋關鍵字。


    drawId : var

    搜尋使用的圖紙或 model ID。


    editEnabled : bool

    是否允許編輯項目。

    預設 true。


    filters : var

    搜尋使用的篩選條件。


    fromVariableManager : bool

    是否由 WAVariableManager 呼叫搜尋變數。


    globalVariable : bool

    是否包含 Global 變數。


    includeValue : var

    搜尋時額外包含的項目值。


    isCompleted : bool

    元件是否已完成初始化。


    list : var

    目前搜尋結果列表。


    loadStatus : int

    資料載入狀態（Define.LoadStatus）。


    loading : bool [read-only]

    是否正在載入資料。


    pageRows : int [read-only]

    每頁顯示筆數。


    privateVariable : bool

    是否包含 Private 變數。


    proj : var

    搜尋使用的專案資訊。


    record : var

    搜尋使用的 Record 資訊。


    searchStatus : int

    搜尋狀態（Define.LoadStatus）。


    searching : bool [read-only]

    是否正在搜尋。


    selected : bool [read-only]

    是否已有選取項目。


    selectedName : var

    目前選取項目的名稱。


    total : int

    搜尋結果總筆數。


    type : string

    目前類型。

    預設 "tag"。
