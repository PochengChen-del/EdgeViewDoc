    Detailed Description

    提供年份瀏覽與選擇功能。

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 每 10 年區間 切換控制
    • 自訂年份狀態（selected / disabled）

    年份上方邊距。


    cellVerticalPadding : real

    年份垂直邊距。


    currentYear : int

    目前顯示的年份（用於計算區間）。


    endYear : int [read-only]

    區間結束年份（不包含）。

    對齊至下一個 decade。


    maxCellAdvanceWidth : real [read-only]

    年份按鈕最大寬度，用於對齊。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    startYear : int [read-only]

    區間起始年份（不包含顯示第一個）。

    實際顯示為 (startYear + 1) ~ (endYear - 1)。


    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。
