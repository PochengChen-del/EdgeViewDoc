    Detailed Description

    提供支援圓角遮罩的圖片元件，並支援圖片邊框與圖片縮放模式設定。

    支援功能：

    • 圓角圖片顯示
    • 邊框與背景設定

    Property Documentation

    borderColor : color

    邊框顏色。


    borderWidth : real

    邊框寬度。

    預設 0。


    fillMode : enumeration

    圖片填滿模式。

    預設 Image.PreserveAspectFit 。


    horizontalAlignment : enumeration

    圖片水平對齊位置。


    source : url

    圖片來源 URL。

    詳細格式與限制請參考 Qt 官方文件。


    sourceSize : size

    圖片載入尺寸。


    status : enumeration

    目前圖片載入狀態。


    verticalAlignment : enumeration

    圖片垂直對齊位置。
