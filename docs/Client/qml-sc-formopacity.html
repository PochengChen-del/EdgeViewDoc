    Detailed Description

    提供透明度數值(0~255)輸入，並以滑桿與文字輸入框同步控制。

    元件內部由 FormSlider 與 FormTextField 組成：

    • 左側滑桿用於直覺調整透明度，拖動滑桿時，文字輸入框會同步更新
    • 右側輸入框用於精確輸入數值，輸入有效數值時，滑桿位置會同步更新

    透明度會套用於顯示色塊（color），以視覺方式呈現目前 opacity。

    此元件與其他 Form 元件提供一致的表單互動行為與樣式，並透過 wavalidator 提供驗證功能。

    Property Documentation

    color : color

    顯示透明度效果的基底顏色。

    實際顯示時會依據 value 計算 opacity。


    from : int

    最小值。

    預設 0。


    ratio : real [read-only]

    透明度比例（0.0 ~ 1.0）。計算方式為 value / 255。


    stepSize : int

    調整步進值。

    預設 1。


    to : int

    最大值。

    預設 255。


    value : int

    目前透明度數值。

    範圍為 from ~ to。


    wavalidator : Validator

    欄位驗證器，包含錯誤訊息、必填。

    使用驗證時，請在 signal validated(var val) 觸發後，再確認驗證結果 -> valueChanged 事件發生較晚。


    wheelEnabled : bool

    是否允許滑鼠滾輪調整數值。
