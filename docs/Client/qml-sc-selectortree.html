    Detailed Description

    提供顯示樹狀選項清單。

    支援功能：

    • 系統主題切換（systemThemeName）
    • 文字顯示（textRole, descRole）
    • 圖示顯示
    • 樹狀層級層級控制
    • 選取控制

    Property Documentation

    defaultExpanded : bool

    預設展開狀態。

    • true → 展開
    • false → 收合

    optionShowFold(var opt) : bool

    判斷該選項是否顯示收折按鈕（hideFold）。

    \paramopt 選項資料 \return bool


    parentIndexesRole : string

    父節點路徑欄位名稱。

    預設 "parentIndexes"。

    內容以 parentIndexesSeparator 分隔的字串，例如： "0.1.3"。


    parentIndexesSeparator : string

    父節點索引字串的分隔符號。

    預設 "."。
