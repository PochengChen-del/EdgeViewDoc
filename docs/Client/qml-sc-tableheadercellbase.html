    Detailed Description

    TableHeaderCellBase

    是 TableHeaderCell 的基礎元件。

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）

    Property Documentation

    bottomPadding : real

    下方邊距。


    divColor : color

    分隔線顏色。


    divHorizontalAlignment : int

    分隔線水平對齊方式。

    預設 Qt.AlignRight。

    ConstantDescription
    Qt.AlignLeft靠左
    Qt.AlignHCenter置中
    Qt.AlignRight靠右

    divWidth : real

    分隔線寬度。


    items : Item

    單元格自訂內容。


    leftPadding : real

    左方邊距。


    padding : real

    邊距。


    rightPadding : real

    右方邊距。


    showDiv : bool

    是否顯示底部分隔線。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    spacing : real

    間距。


    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。


    topPadding : real

    上方邊距。
