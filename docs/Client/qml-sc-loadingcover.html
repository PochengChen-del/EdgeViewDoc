    Detailed Description

    提供

    parent 區域載入狀態顯示，且以遮罩方式阻擋畫面上的操作。

    元件組成：

    • 載入圖示
    • 提示文字
    • 遮罩背景

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 文字顯示（text）
    • 顯示與動畫控制（loading）

    Property Documentation

    backgroundColor : color

    遮罩背景顏色。


    backgroundRadius : real

    遮罩背景圓角半徑。


    duration : int

    動畫一圈時間（毫秒）。


    imageWidth : real

    載入圖示大小。


    loading : bool

    是否顯示載入狀態。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.ExtraSmall超小尺寸
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    text : string

    顯示文字。


    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。
