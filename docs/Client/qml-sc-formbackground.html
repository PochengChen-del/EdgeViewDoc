    Detailed Description

    提供表單元件統一的背景樣式。

    支援功能：

    • 邊框（border）
    • 圓角（radius）
    • 陰影（shadowColor）
    • 漸層覆蓋（coverGradient）

    此元件通常搭配輸入元件使用（例如 FormTextField），並透過外部狀態（state）控制顏色、邊框與陰影表現。
