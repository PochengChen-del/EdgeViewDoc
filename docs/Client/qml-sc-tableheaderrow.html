    Detailed Description

    TableHeaderRow

    用於 TableList 的 header。

    支援功能：

    • 子元件統計

    Property Documentation

    availableHeight : real [read-only]

    可用高度（扣除 topPadding 與 bottomPadding）。


    availableWidth : real [read-only]

    可用寬度（扣除 leftPadding 與 rightPadding）。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    visibleCount : int [read-only]

    可見子元件數量。


    visibleData : var [read-only]

    統計可見子元件資訊。

    包含：

    • count: 可見數量
    • implicitWidth: 所有子元件總寬度（含 spacing）
    • implicitHeight: 最大子元件高度

    visibleImplicitHeight : real [read-only]

    所有可見子元件中的最大 implicitHeight。


    visibleImplicitWidth : real [read-only]

    所有可見子元件的總 implicitWidth（含 spacing）。
