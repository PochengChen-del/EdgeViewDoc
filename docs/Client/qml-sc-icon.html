    Detailed Description

    Icon

    元件用於顯示 SVG 向量圖示，並支援顏色覆蓋（Color Overlay）。 預設會保持圖示比例縮放，並可透過 color 屬性動態改變顯示顏色。

    元件透過 OpacityMask 機制，將 color 套用至圖示形狀。

    Property Documentation

    color : color

    圖示顏色。

    預設 "transparent"，表示使用圖示原始顏色。

    當設定為非透明顏色時，會透過 OpacityMask 將顏色套用至圖示形狀。


    colorEnabled : bool

    是否啟用顏色覆蓋。

    當為 true 時，會使用 color 套用顏色覆蓋。


    fillMode : enumeration

    圖示填充模式。

    預設 Image.PreserveAspectFit。

    詳細格式與限制請參考 Qt 官方文件。


    source : url

    圖示來源 URL，建議為 SVG 格式。

    詳細格式與限制請參考 Qt 官方文件。
