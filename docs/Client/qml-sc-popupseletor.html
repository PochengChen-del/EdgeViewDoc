    Detailed Description

    選擇輸入元件的彈出容器，用於有彈跳框的輸入元件。

    元件組成：

    • Header：標題列與操作區
    • Body：主體內容
    • Footer：底部操作區

    支援功能：

    • 主題樣式控制（themeName）
    • 顯示模式（position）
      • Relative（依附於來源元件）
      • Bottom（全螢幕底部彈出）
    • 大小控制

    Body 可用高度（扣除 Header 與 Footer）。

    主體元件。

    Popup 主體內容（Body 區域），放置自訂 UI 元件，例如列表、表單、選擇器...。


    borderColor : color

    邊框顏色。


    borderWidth : real

    邊框寬度。


    contentAvailableHeight : real [read-only]

    顯示可用高度 (扣除 minTopMargins)。


    dividerColor : color

    分隔線顏色。


    dragHandleColor : color

    拖曳把手顏色。


    fixedHeight : bool

    是否固定高度。

    預設 false。

    • true → 禁止拖曳修改高度。
    • false → 可以拖曳改變高度。

    Footer 背景顏色。

    Footer height。


    footerImplicitWidth : real [read-only]

    Footer implicitWidth。

    Footer 元件。


    headerBackgroundColor : color

    Header 背景顏色。


    headerHeight : real [read-only]

    Header height。


    headerImplicitWidth : real [read-only]

    Header implicitWidth。


    leftHeaderItems : Item

    Header 左方元件。


    maskColor : color

    Bottom 模式遮罩顏色。


    maxAroundHeight : real

    上下可見範圍最大高度。

    bindingMaxAroundHeight = true，每次 open 時計算。


    maxBodyHeight : real [read-only]

    Body 最大可用高度（扣除 Header 與 Footer）。


    maxContentHeight : real

    最大內容高度，限制可視高度範圍。


    minBodyHeight : real [read-only]

    Body 最小可用高度（扣除 Header 與 Footer）。

    最小內容高度（Header + Footer）。

    與上方邊界最小邊距。
