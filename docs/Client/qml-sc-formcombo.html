    Detailed Description

    FormCombo

    作為 表單輸入元件 的容器，負責排列子元件並提供組合顯示所需的資訊（例如數量與位置）。

    子元件可透過 isCombo 與相關屬性，自動調整圓角與邊界重疊行為。

    Property Documentation

    activeState : State [read-only]

    active 狀態設定。


    actived : bool

    是否有任一子元件處於 active 狀態。

    此屬性會統計 contentItems 中所有子元件的 actived 狀態， 當任一子元件為 active（例如取得焦點或展開）時， FormCombo 會進入 active 狀態。

    通常用於控制整體樣式（例如標題顏色或提示樣式）， 以反映目前操作中的欄位。

    Note: 此屬性為唯讀聚合結果。


    contentItems : Item

    表單元件。

    限使用 Form 開頭的表單欄位元件。


    disableState : State [read-only]

    disable 狀態設定。


    hint : string

    提示文字。


    hintColor : StateColor

    各狀態提示文字顏色設定。


    hoverState : State [read-only]

    hover 狀態設定。


    hovered : bool

    是否有任一子元件處於 hover 狀態。

    此屬性會統計 contentItems 中所有子元件的 hovered 狀態， 當任一子元件為 hover 時，整個 FormCombo 即視為 hover 狀態。

    主要用於同步控制外層容器的 state， 讓標題（title）與提示文字（l hint）能根據子元件互動狀態 顯示對應樣式。

    Note: 此屬性為唯讀聚合結果，實際 hover 狀態由各子元件控制。


    invalid : bool

    是否有任一子元件處於驗證錯誤狀態。

    此屬性會統計 contentItems 中所有子元件的 invalid 狀態， 當任一子元件驗證失敗時，整個 FormCombo 即視為 invalid。

    當為 true 時：

    • 標題與提示文字會套用錯誤樣式（依 themeStyle）
    • FormAssistiveText 會顯示所有子元件的錯誤訊息

    Note: 此屬性為唯讀聚合結果。


    isRequired : bool

    是否必填。


    normalState : State [read-only]

    normal 狀態設定。


    readOnly : bool

    是否唯讀。


    readonlyState : State [read-only]

    readonly 狀態設定。


    reqdColor : StateColor

    各狀態必填星號顏色設定。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription

    Define.SizeType.Medium中尺寸

    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。


    title : string

    標題文字。


    titleColor : StateColor

    各狀態標題文字顏色設定。
