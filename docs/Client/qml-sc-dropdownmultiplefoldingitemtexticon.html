    Detailed Description

    DropdownMultipleFoldingItemTextIcon

    是 DropdownMultipleFoldingItemBase 的實作元件。

    支援功能：

    • 主題樣式控制（themeName）
    • 文字顯示（text, description）
    • 圖示顯示（iconSourceUrl）
    • 選取控制（checked, checkState）
    • 收折控制（showFold, expanded）
