    Detailed Description

    提供文字輸入。

    此元件與其他輸入元件提供一致的互動行為與樣式，並透過 wavalidator 提供驗證功能。

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 前綴與後綴文字（prefix、l suffix）
    • 圖示顯示（iconSourceUrl）
    • 清除按鈕（showClear）
    • 左右擴展元件（leftItem、l rightItem）
    • 密碼遮罩（passwordCharacter、passwordMaskDelay）
    • 文字選取與樣式控制（selectionColor、selectedTextColor）

    元件內建互動狀態：

    • normal
    • hover
    • active
    • disable
    • readonly

    各狀態會繼承對應的 base state（例如 normal → normalbase）， 並透過 themeStyle 套用背景、邊框與內容顏色等。

    圖示來源 URL。

    暫時使用 string 型別。

    是否為組合按鈕。

    是否為驗證錯誤狀態。

    預設綁定 wavalidator.error。
