    Detailed Description

    提供二維（X/Y）數值調整（例如

    Saturation）。

    Property Documentation

    color : color

    背景顏色。


    coverColor : color

    覆蓋層顏色。


    coverGradient : Gradient

    覆蓋層漸層色。


    gradient : Gradient

    背景漸層色。


    indicatorWidth : real

    指示器寬度。


    radius : real

    圓角半徑。

    預設 4。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。


    xValue : real

    垂直值（0.0 ~ 1.0），對應指示器的 Y 軸位置。

    由外部根據位置更新。


    yValue : real

    垂直值（0.0 ~ 1.0），對應指示器的 Y 軸位置。

    由外部根據位置更新。
