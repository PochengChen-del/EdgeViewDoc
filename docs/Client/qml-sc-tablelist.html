    Detailed Description

    提供完整資料表結構，包含

    TopBar、Header、Body、Footer 與提示訊息區域， 並支援資料顯示、滾動控制與操作區域配置。

    元件組成：

    • TopBar：上方操作區
    • Header：欄位標題列（可水平同步滾動）
    • Body：資料列表（WAListView）
    • Footer：底部操作區
    • Assistive：提示訊息

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 滾動控制
      • 垂直滾動：Body
      • 水平滾動：Header 與 Body 同步
    • 動態內容尺寸計算
    • 自訂操作元件
      • TopBar（rightTopBarItems, leftTopBarItems）
      • Header（header）
      • Body（delegate）
      • Footer（rightFooterItems, leftFooterItems）
    • 提示文字顯示（showHint, hint）
