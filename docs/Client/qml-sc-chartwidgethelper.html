    Detailed Description

    ChartWidgetHelper handles data log queries, interval calculations, and format conversions for various chart types including XY plots, state timelines, and trend charts.

    Property Documentation

    datalogFrom : var

    This property holds the data log source configuration object.

    Configures whether data log queries target tags or records, including record name and column mapping information.


    datalogMaxRecord : int

    This property holds the maximum number of data log records to retrieve.


    datalogRawdataMaxRecord : int

    This property holds the maximum number of raw data log records to retrieve.


    editor : QtObject

    This property holds the editor context object used for project identification in data source queries.


    isFromRecord : bool [read-only]

    Returns true when datalogFrom is configured to query from a record source, and false when querying from tags.


    timeTitle : string [read-only]

    This property holds the column title used for the time axis in data log results.


    Method Documentation

    colorCompatibleRGBA(fromColor, a)

    Converts fromColor to an RGBA color string with optional alpha a.

    Returns a CSS-compatible rgba() string, or undefined if the color cannot be converted.


    getChartJsIntervalType(invTp)

    Converts the invTp interval type from getDataLogIntervals format to a Chart.js-compatible time unit string.

    Returns one of "year", "month", "day", "hour", "minute", or "second". Defaults to "minute" if invTp is unrecognized.


    getDataLog(datalogTargets, st, en, cn, inv, invTp)

    Retrieves historical data log entries including raw data and aggregated logs.

    datalogTargets specifies the query targets as an array of objects with Name, DataType, and _dataType fields. st and en define the time range in milliseconds. cn specifies the total record count; pass 0 for raw data queries. inv specifies the sampling interval in milliseconds; pass 0 for raw data queries. invTp specifies the interval type: S or sec for seconds, M or min for minutes, H or hour for hours, D or day for days, month for months, year for years.

    Returns a Promise that resolves to an object with targets and values arrays:

    {
    "targets": [{ "Name": "time" }, { "Name": "Tag1", ... }],
    "values": [[timestamp, value1, value2, ...], ...]
}

    See also getRawDataLog() and getDataLogIntervals().


    getDataLogIntervals(startUnixMs, endUnixMs, interval)

    Calculates data log interval parameters including total count, interval size, and interval type for queries between startUnixMs and endUnixMs with the given interval in milliseconds.

    Returns an object with totalCount, inv, and invTp properties.


    getRawDataIntervalType(st, en, invTp)

    Returns the best-fit interval type for raw data queries between st and en, based on the configured raw data max record limit.

    If the computed interval exceeds the resolution of invTp, returns the computed type; otherwise returns invTp.


    stTimelineFormatConvert(startTimeMs, endTimeMs, res)

    Converts raw data log res into state timeline format between startTimeMs and endTimeMs.

    Returns an array of objects, each with target and datapoints properties for timeline rendering.


    syncHexDataColor(wgt)

    Converts color objects in the wgt data list to hexadecimal string format.

    Iterates over the wgt data list and replaces backgroundColor and borderColor objects with their string representations.


    syncPropertyDataListNBinding(wgt)

    Synchronizes property data list titles with binding targets.

    Iterates over the wgt data list and updates titles from matching binding entries. Only updates titles when data items do not have a custom title set.

    See also syncHexDataColor().


    trendFormatConvert(startTimeMs, endTimeMs, res, chartData)

    Converts raw data log res into trend chart format for chartData between startTimeMs and endTimeMs.

    Values outside the span range are clamped. Boundary values at the start and end times are inserted if missing. Returns the updated chartData array.


    xyplotFormatConvert(startTimeMs, endTimeMs, res, chartData)

    Converts raw data log res into XY plot format for chartData between startTimeMs and endTimeMs.

    Values outside the span range (spanHi / spanLo) are clamped. Returns the updated chartData array.
