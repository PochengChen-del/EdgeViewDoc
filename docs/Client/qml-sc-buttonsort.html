    Detailed Description

    此元件提供列表排序切換功能，點擊時會在升冪與降冪之間切換。

    圖示會依據 sortType 自動切換對應狀態：

    • 無排序（-1）
    • 升冪（Qt.AscendingOrder）
    • 降冪（Qt.DescendingOrder）

    各狀態會對應不同的 SVG 圖示資源。
