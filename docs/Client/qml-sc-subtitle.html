    Detailed Description

    提供顯示顯示標題與補充說明的文字區塊元件，且支援單行或多行排版。

    支援功能：

    • 系統主題切換（systemThemeName）
    • 文字排版控制（elide/wrap/line count）

    Property Documentation

    availableWidth : real [read-only]

    可用顯示寬度（扣除 leftPadding 與 rightPadding）。


    description : string

    描述文字。


    descriptionElide : enumeration

    描述文字省略模式。


    descriptionMaximumLineCount : int

    描述文字最大行數限制。

    當 textWrapMode 允許多行時，此屬性用來限制最多顯示行數。設為 0 表示不限制行數。


    descriptionWrapMode : enumeration

    描述文字換行模式。


    text : string

    副標題文字。


    textElide : enumeration

    副標題文字省略模式。


    textMaximumLineCount : int

    副標題文字最大行數限制。

    當 textWrapMode 允許多行時，此屬性用來限制最多顯示行數。設為 0 表示不限制行數。


    textWrapMode : enumeration

    副標題文字換行模式。


    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。
