    Detailed Description

    WAToolTipThumbnail

    為 WAToolTip1 的擴充元件，提供縮圖提示框。

    Property Documentation

    elide : enumeration

    文字省略模式。


    imageMaxHeight : real

    縮圖最大高度。


    imageMaxWidth : real

    縮圖最大寬度。


    imageSizeFixed : bool

    縮圖尺寸固定。


    imageSizeRatio : real

    縮圖尺寸固定比例。

    若 imageSizeFixed 為 true，圖片會依此比例固定顯示大小。

    預設 0.5625 (16:9)


    lineHeight : real

    文字行高。


    maximumLineCount : int

    文字最大行數限制。

    當 wrapMode 允許多行時，此屬性用來限制最多顯示行數。設為 0 表示不限制行數。


    showImageBackground : bool

    是否顯示縮圖背景。


    showText : bool

    是否顯示文字。


    source : url

    縮圖來源 URL。


    textHorizontalAlignment : enumeration

    文字水平對齊方式。


    textVerticalAlignment : enumeration

    文字垂直對齊方式。


    wrapMode : enumeration

    文字換行模式。
