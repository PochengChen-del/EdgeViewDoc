    Detailed Description

    提供時間瀏覽與選擇功能。

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 時間清單顯示（model）
    • 點擊選取事件

    cellSpacing : real

    時間項目間距。


    cellTopPadding : real

    時間項目上方邊距。


    cellVerticalPadding : real

    時間垂直邊距。


    is24Hour : bool

    是否使用 24 小時制。

    預設依據 Define.dateDisplayFormat 判斷。


    maxCellAdvanceWidth : real [read-only]

    時間項目最大寬度。


    meridiemPosition : int

    AM/PM 顯示位置。


    showMinute : bool

    是否顯示分鐘。


    showSecond : bool

    是否顯示秒數。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription

    Define.SizeType.Medium中尺寸
