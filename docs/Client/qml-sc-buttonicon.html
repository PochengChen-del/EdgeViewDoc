    Detailed Description

    ButtonIcon

    為以圖示為主要內容的按鈕元件， 繼承自 ButtonBase，並擴充圖示（Icon）相關狀態控制。

    Property Documentation

    iconColor : StateColor

    各狀態圖示顏色設定。


    iconSourceUrl : url

    圖示來源 URL。

    詳細格式與限制請參考 Qt 官方文件。

    暫時使用 string 型別。


    iconText : string

    圖示文字內容。


    iconTextColor : StateColor

    各狀態圖示文字顏色設定。


    showIconText : bool

    是否顯示圖示文字。
