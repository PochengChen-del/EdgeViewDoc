    Detailed Description

    提供側邊欄框架。

    元件組成：

    • Header：標題列與關閉按鈕
    • Content：主要內容區域
    • Footer：底部操作區域

    支援功能：

    • 主題樣式控制（themeName）
    • 自訂內容區（contentItem）
    • 自訂 Footer 區域（footerItems）
    • 展開/收合控制（expand() / collapse()）

    Property Documentation

    contentItem : Item

    內容區域的子元件。


    expanded : bool [read-only]

    是否展開。

    此屬性會同步父層容器的 expanded 狀態。


    footerItems : Item

    Footer 元件。


    showFooter : bool

    是否顯示 Footer。


    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。


    title : string

    標題文字。


    Signal Documentation

    closeClicked()

    點擊關閉按鈕時觸發。

    Note: The corresponding handler is onCloseClicked.


    Method Documentation

    collapse()

    收合側邊欄。

    若父元件存在 collapse() 方法則會自動呼叫。


    expand()

    展開側邊欄。

    若父元件存在 expand() 方法則會自動呼叫。


    object getThemeStyle()

    取得主題樣式設定物件。

    \return主題樣式設定物件。
