    Detailed Description

    提供應用程式的主要框架。

    元件組成：

    • Header：系統標題與功能按鈕
    • Navbar：側邊導覽
    • Page：頁面內容

    支援功能：

    • 主題樣式控制（themeName）
    • Header 功能觸發
    • 導覽列控制
    • 自訂頁面內容（pageItem）

    使用：

    MainLayout {
    anchors.fill: parent
    pageItem: PageLayout {
        anchors.fill: parent
    }
}
