    Detailed Description

    提供顯示多筆錯誤訊息列表。

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 顯示模式（position）
      • Relative（依附於來源元件）
      • Bottom（全螢幕底部彈出）
    • 大小控制
    • 滾動控制
    • 錯誤訊息列表顯示（errorModel）

    Property Documentation

    errorTitleRole : string

    預設 "title"。
