    Detailed Description

    提供資料表（TableList）使用的分頁控制元件，整合頁碼切換與每頁筆數設定功能。

    元件組成：

    • Pagination：頁碼控制
    • Dropdown：每頁顯示筆數設定

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 頁碼顯示（currentPage, total）
    • 頁碼切換控制
    • 每頁筆數切換（rows per page）

    Property Documentation

    currentPage : int

    目前頁碼。範圍為 1 ~ totalPage，超出範圍會自動修正。


    pageRows : var

    目前選擇的每頁筆數值。


    pageRowsIndex : int

    目前選擇的每頁筆數索引。


    pageRowsModel : var

    每頁筆數選項資料來源。

    預設 Define.rowsPerPages。


    radius : real

    按鈕圓角半徑。


    showPageRows : bool

    是否顯示每頁筆數選單。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    totalPage : int [required]

    總頁數。

    注意：必須大於等於 1。
