    Detailed Description

    提供表單副標題與描述文字、收折按鈕與自訂操作按鈕。

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 展開／收折狀態控制（expanded）
    • 標題、描述與標籤顯示
    • 自訂操作按鈕

    Property Documentation

    actions : Item

    右側操作按鈕區域的子元件。


    bottomPadding : real

    下方邊距。


    description : string

    描述文字。


    expanded : bool

    是否展開。

    預設 true。

    • true → 展開
    • false → 收折

    labelColorType : enumeration

    標籤顏色類型。

    對應 WAColor.ColorType。


    labelStyle : enumeration

    標籤樣式。

    對應 Define.LabelStyle。


    labelText : string

    標籤文字。


    leftPadding : real

    左方邊距。


    padding : real

    邊距。


    rightPadding : real

    右方邊距。


    showActions : bool

    是否顯示右側操作按鈕區域。


    showDescription : bool

    是否顯示描述文字。


    showFold : bool

    是否顯示收折按鈕。


    showLabel : bool

    是否顯示標籤。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。


    title : string

    標題文字。


    topPadding : real

    上方邊距。
