    Detailed Description

    此元件負責管理

    Picker 之間的切換邏輯：

    • DatePicker（日期選擇）
    • MonthPicker（月份選擇）
    • YearPicker（年份選擇）

    Property Documentation

    currentDate : int [read-only]

    目前日期（1–31）。


    currentDateTime : date

    目前選擇的完整日期。


    currentMonth : int [read-only]

    目前月份（0–11）。


    currentPickType : string

    目前頁面類型（date / month / year）。


    currentYear : int [read-only]

    目前年份。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。
