    Detailed Description

    用於行動版

    UI 中，提供包含圖示與文字的搜尋觸發按鈕，作為搜尋 UI 的入口控制元件。

    支援功能：

    • 主題樣式控制（themeName）
    • 文字顯示（text）
    • 圖示顯示（iconSourceUrl）

    元件內建互動狀態：

    • normal
    • hover
    • active
    • disable

    各狀態會繼承對應的 base state（例如 normal → normalbase）， 並透過 themeStyle 套用背景、邊框與內容顏色等。
