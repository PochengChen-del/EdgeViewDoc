    Detailed Description

    提供可滾動容器，並針對

    ScrollBar 進行樣式客製。

    支援功能：

    • 主題樣式控制（themeName）
    • 垂直與水平滾動
    • 自動顯示/隱藏捲軸（依內容尺寸判斷）
      • 垂直捲軸：當 contentHeight > height 時顯示
      • 水平捲軸：當 contentWidth > width 時顯示
    • 自訂捲軸（scrollBarWidth, scrollBarColor）
    • 滾動邊界限制（scrollOver）

    Property Documentation

    scrollBarColor : color

    捲軸顏色。


    scrollBarWidth : real

    捲軸寬度。


    scrollOver : bool

    是否允許 ScrollBar 超出有效範圍。

    預設 false。


    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。
