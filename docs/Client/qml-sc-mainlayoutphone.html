    Detailed Description

    提供手機裝置應用程式的主要框架。

    元件組成：

    • Header：標題列與功能按鈕
    • Navbar：側邊導覽
    • Page：頁面內容
    • Overlay：覆蓋頁面

    支援功能：

    • 主題樣式控制（themeName）
    • Header 功能觸發（headerFuncModel）
    • 導覽列控制（navModel）
    • 覆蓋頁面管理
    • 自訂頁面內容（pageItem）

    使用：

    MainLayoutPhone {
    anchors.fill: parent
    pageItem: Item {
        anchors.fill: parent
    }
}
