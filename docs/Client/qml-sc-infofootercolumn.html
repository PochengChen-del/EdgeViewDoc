    Detailed Description

    提供未登入頁面的底部資訊與功能按鈕。

    元件組成：

    • 公司版權資訊
    • 系統版本資訊（自訂）
    • 功能按鈕列表
    • 語言切換下拉選單

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 功能按鈕控制
    • 語言切換

    Property Documentation

    availableWidth : real [read-only]

    可用寬度（扣除 leftPadding 與 rightPadding）。


    buttonKeyRole : string

    按鈕文字欄位名稱。

    預設 "key"。


    buttonModel : var

    功能按鈕來源。


    buttonOpenUrlRole : string

    按鈕開啟 URL 欄位名稱。

    若存在且為有效字串，點擊時會呼叫 Global.openUrlExternally()。


    showVersion : bool

    是否顯示版本資訊。

    預設 true。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。


    today : date

    今日日期，用於顯示版權年份。


    versionText : string

    系統版本資訊文字，使用換行字元（\n）分隔多組。
