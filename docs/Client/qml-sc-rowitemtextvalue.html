    Detailed Description

    RowItemTextValue

    是 RowItemBase 的實作元件。

    提供顯示左側文字與右側對應值。

    支援功能：

    • 主題樣式控制（themeName）
    • 文字顯示（text）
    • 值顯示（value）

    Property Documentation

    showValue : bool

    是否顯示右側值。


    text : string

    顯示文字。


    textElide : enumeration

    文字省略模式。


    textFont : font

    文字字型。


    textLineCount : int [read-only]

    文字實際顯示行數。


    textLineHeight : real

    文字行高。


    textMaxLineCount : int

    文字最大行數限制。

    右側值實際顯示行數。


    valueLineHeight : real

    右側值行高。


    valueMaxLineCount : int

    右側值最大行數限制。

    當 textWrapMode 允許多行時，此屬性用來限制最多顯示行數。設為 0 表示不限制行數。


    valueMinWidth : real

    右側值最小寬度。

    確保右側值在內容寬度過短時，仍保有基本顯示寬度，同時避免擠壓左側文字。

    預設 48。
