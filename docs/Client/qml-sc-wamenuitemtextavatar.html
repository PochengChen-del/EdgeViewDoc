    Detailed Description

    WAMenuItemTextAvatar

    為顯示文字與 AvatarText 的菜單項目。 繼承 WAMenuItemBase，並擴充文字相關狀態控制。

    支援功能：

    • 文字顯示（text, \lsuffix）
    • AvatarText 顯示（avatarText）

    Property Documentation
