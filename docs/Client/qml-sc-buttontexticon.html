    Detailed Description

    ButtonTextIcon

    為同時顯示文字與圖示的按鈕元件， 繼承 ButtonBase，並擴充文字與圖示相關狀態控制。

    圖示可透過 iconAlign 控制相對位置， 並支援水平或垂直排列。

    Property Documentation

    iconAlign : int

    圖示相對於文字的位置。

    預設 Qt.AlignLeft。

    ConstantDescription
    Qt.AlignLeft左方。
    Qt.AlignRight右方。
    Qt.AlignTop上方。
    Qt.AlignBottom下方。

    iconColor : StateColor

    各狀態圖示顏色設定。


    iconSourceUrl : url

    圖示來源 URL。

    詳細格式與限制請參考 Qt 官方文件。

    暫時使用 string 型別。


    iconText : string

    圖示文字內容。


    iconTextColor : StateColor

    各狀態圖示文字顏色設定。


    isVertical : bool [read-only]

    圖示與文字是否垂直排列。

    當 iconAlign 為 Qt.AlignTop 或 Qt.AlignBottom 時為 true。


    lineHeight : real

    文字行高。


    showIcon : bool

    是否顯示圖示。


    showIconText : bool

    是否顯示圖示文字。


    textColor : StateColor

    各狀態文字顏色設定。
