    Detailed Description

    提供頁籤切換使用的按鈕元件，通常與

    WATabBar1 搭配使用，與 WATabBar1 的模式與樣式設定自動同步。

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 風格與模式顯示（mode, style）
    • 文字顯示（showText, text）
    • 圖示顯示（showIcon, iconSourceUrl）
    • 數量標籤顯示（showCount, count）
    • 關閉按鈕（showClose, removeClicked）

    元件內建互動狀態：

    • normal
    • hover
    • active
    • disable

    各狀態會繼承對應的 base state（例如 normal → normalbase）， 並透過 themeStyle 套用背景、邊框與內容顏色等。

    數量標籤顏色類型。

    disable 狀態基礎設定。由 disable 繼承。


    disableState : State

    disable 狀態設定（繼承 disablebase）。


    hoverBaseState : State [read-only]

    hover 狀態基礎設定。由 hover 繼承。


    hoverState : State

    hover 狀態設定（繼承 hoverbase）。


    iconColor : StateColor

    各狀態圖示顏色設定。


    iconSourceUrl : url

    圖示來源 URL。

    詳細格式與限制請參考 Qt 官方文件。


    isSideBar : bool [read-only]

    是否為 Side bar 模式。


    isText : bool [read-only]

    是否為文字樣式。


    lineHeight : real

    文字行高。


    mode : int

    顯示模式。

    預設會從父元件繼承，若未提供則使用 0。

    ConstantDescription
    0Main
    1Side bar

    normalBaseState : State [read-only]

    normal 狀態基礎設定。由 normal 繼承。


    normalState : State

    normal 狀態設定（繼承 normalbase）。


    radius : real

    按鈕圓角半徑。

    預設 8。


    showClose : bool

    是否顯示關閉按鈕。


    showCount : bool

    是否顯示數量標籤。


    showIcon : bool

    是否顯示圖示。


    showText : bool

    是否顯示文字。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    style : int

    顯示樣式

    預設會從父元件繼承，若未提供則使用 Define.ButtonStyle.Filled。

    ConstantDescription
    Define.ButtonStyle.Filled填充樣式。
    Define.ButtonStyle.Text純文字樣式。

    textColor : StateColor

    各狀態文字顏色設定。


    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。
