    Detailed Description

    BaseWidget

    是所有可視化 Widget 的基礎類別，提供：

    • 變形（旋轉、縮放、平移）
    • 動畫與事件觸發機制
    • Drawing 座標與層級計算
    • 編輯模式輔助資訊

    此類別通常不直接使用，而是由具體 Widget 繼承。

    Property Documentation

    angle2Drawing : real [read-only]

    相對於 Drawing 的旋轉角度。


    animations : var

    動畫設定物件。

    animations

    包含 displays、frame、actions、path 等動畫與互動設定， 其結構由系統內部定義，通常由編輯器產生。


    level : int [read-only]

    Widget 在 Drawing 中的層級。


    offset2Drawing : point [read-only]

    相對於 Drawing 的位移。


    type : string [read-only]

    Widget 類型識別字串。


    Signal Documentation

    afterPositionChanged(real diffX, real diffY)

    在 Widget 位置變更完成後發送。

    Note: The corresponding handler is onAfterPositionChanged.


    afterSizeChanged(real diffWidth, real diffHeight)

    在 Widget 尺寸變更完成後發送。

    Note: The corresponding handler is onAfterSizeChanged.

    errorObject _validateValue(string type, var value, object args)

    驗證值是否正確。 共用 function。

    \paramtype 驗證型別。 \param value 值。 \param args 驗證相關參數。 \return 驗證錯誤內容。驗鄭成功為 undefined；驗鄭失敗為 errorObject, errorObject format: { "type": "type", "valueType": "prototype value", "errors": [ { "name": "key", "error": errorObject } ] } ex: { "type": "gradient", "valueType": "object",, "errors": [ { "name": "color", "error": { "type": "color", "valueType": "number", } } ] }

    void applyThemeProperties(object theme, bool deep, bool isRecord, int recordIndex, var refObjRecord)

    所有樣式屬性套用主題。 共用 function。

    \paramtheme 主題。 \param deep 是否處理下一層 widget，預設 true。 \param isRecord 是否記錄復原/重作，預設 true。 \param recordIndex 記錄索引，預設 -1。 \param refObjRecord 記錄的資訊參考物件。


    object checkPropertyValid(string propertyName, var propertyValue, object referenceProperties)

    驗證屬性值是否正確。 共用 function。

    \parampropertyName 屬性名稱。 \param propertyValue 屬性值。 \param referenceProperties 關聯屬性。 \return 驗證錯誤內容。驗鄭成功為 null；驗鄭失敗為 object, format: { "name": property name, "error": errorObject, } ex: { "name": "width", "error": { "type": "double", "valueType": "string", } }


    errorObject checkPropertyValidByType(string type, var value, object args)

    驗證值是否正確。 此方法可以由繼承 Widget 覆寫。

    param 和 return 請參考 BaseWidget::_validateValue(string type, var value, object args) args.propertyName 為驗證的屬性名稱。 args.referenceProperties 為關聯屬性。

    object getInitialProperties(object customProperties, object customParent)

    取得初始化的屬性值。主要提供 與原本屬性預設值不同 或 會依其他屬性而有不同初始值的屬性。 此方法由繼承 Widget 覆寫。未覆寫會預設提供 { width: 50, height: 50 } 主要在建立 widget 時取用。

    \paramcustomProperties 指定屬性值。 \param customParent 指定 parent。 \return 初始化的屬性值。object, format: { property name: property value } ex: { width: 50, height: 50 }


    var getPropertyDefaultValue(string propertyName, object theme, ... args)

    取得屬性預設值，並套用主題設定。 此方法由繼承 Widget 覆寫。 主要在 widget 取得屬性內容預設值，並套用主題設定。例如： dataList。

    \parampropertyName 完整的屬性名稱組合，使用 . 串聯。 \param theme 主題設定。 \param args 其他參數。 \return 屬性預設值。


    var getPropertyValue(string propertyName, object theme, bool allowNonExist)

    取得目前屬性值，並套用主題。 共用 function。

    \parampropertyName 完整的屬性名稱組合，使用 . 串聯。 \param theme 主題設定。 \param allowNonExist 是否允許屬性不存回傳 undefined。false：取得預設值，getPropertyDefaultValue()。 \return 套用主題後目前屬性值。


    object[] getStylePropertyList(bool isCreate = false)

    取得樣式屬性清單。與主題套用樣式相關的屬性。 此方法由繼承 Widget 覆寫。

    \paramisCreate 是否包含建立。 \return 樣式屬性清單。object[], format: [ { "name": property name, // 完整的屬性名稱組合，使用 . 串聯，陣列非特定數量可以使用 [] 表示所有項目。 "createOnly": bool, // 只有在建立時套用 } ] ex: { width: 50, height: 50 }
