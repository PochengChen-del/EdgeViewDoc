    Detailed Description

    提供顯示與管理使用者最近的搜尋紀錄。

    支援功能：

    • 系統主題切換（systemThemeName）
    • 紀錄處理（recentKey, maxRecent）
      • 本機快取儲存（wacache）
      • 紀錄新增/刪除/清除
      • 最大筆數限制
    • 點擊選取事件

    Property Documentation

    bottomPadding : real

    下方邊距。


    cacheGroupName : string [read-only]

    快取分組名稱。

    依據環境（host）動態產生，用於區分不同後端環境的資料。


    leftPadding : real

    左方邊距。


    maxRecent : int

    最近紀錄的最大保留數量。

    預設 5。


    recentKey : string

    最近紀錄分類的 key，區分不同搜尋紀錄。


    rightPadding : real

    右方邊距。


    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。
