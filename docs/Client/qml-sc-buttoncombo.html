    Detailed Description

    ButtonCombo

    作為 按鈕（例如 ButtonIcon）的容器，負責排列子元件並提供組合顯示所需的資訊（例如數量與位置）。

    子按鈕可透過 isCombo 與相關屬性，自動調整圓角與邊界重疊行為。

    Property Documentation

    childrenData : var [read-only]

    統計子元件數量與可見數量。


    count : int [read-only]

    子元件數量。


    isCombo : bool [read-only]

    表示此元件為組合容器。

    子按鈕可透過此屬性判斷是否處於組合模式， 以調整圓角與邊界行為。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    style : enumeration

    按鈕樣式類型。

    預設 Define.ButtonStyle.Text。

    ConstantDescription
    Define.ButtonStyle.Outline外框樣式。
    Define.ButtonStyle.Text純文字樣式。
    Define.ButtonStyle.Filled填充樣式。
    Define.ButtonStyle.Hyperlink超連結樣式。

    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    visibleCount : int [read-only]

    可見子元件數量。

    用於子按鈕判斷是否為單一顯示， 例如控制圓角是否完整顯示。
