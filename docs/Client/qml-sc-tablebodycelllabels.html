    Detailed Description

    提供資料表資料列顯示彩色標籤內容。

    支援功能：

    • 單個或多個彩色標籤顯示

    每個資料項會被渲染為一個 ColorLabel。

    Property Documentation

    colorTypeRole : string

    顏色類型欄位名稱。

    預設 "colorType"。


    isArray : bool [read-only]

    判斷目前 model 是否為 Array 型態。


    maxImplicitHeight : real [read-only]

    最大高度（所有 label 換行排列總高度，包含邊距、間距）。


    maxImplicitWidth : real [read-only]

    最大寬度（所有 label 橫向排列總寬度，包含邊距、間距）。


    minImplicitHeight : real [read-only]

    最小高度（所有 label 最大單一高度，包含邊距）。


    minImplicitWidth : real [read-only]

    最小寬度（所有 label 最大單一寬度，包含邊距）。


    model : var

    標籤資料來源。


    textRole : string

    顯示文字欄位名稱。

    預設 "text"。


    Method Documentation

    string i18nText(object opt)

    取得顯示文字（textRole）。

    可覆寫。


    int labelColorType(object opt)

    取得 label 對應的顏色類型。

    若未提供或不存在，會隨機提供顏色。
