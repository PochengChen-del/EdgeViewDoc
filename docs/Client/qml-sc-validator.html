    Detailed Description

    提供通用欄位驗證機制，支援多種規則組合，並依模式自動或延遲觸發驗證。

    支援功能：

    • 多規則字串解析（以 | 分隔）
    • 驗證觸發模式（mode）
    • 多型態資料驗證（string/number/array/file）
    • 自動產生錯誤訊息（支援 i18n）
    • 自訂驗證規則（custom）
    • 與 Validators 整合管理（manager）

    Property Documentation

    actived : bool

    綁定的目標為 active 狀態。


    error : bool [read-only]

    是否有錯誤。


    errorList : var

    錯誤列表。


    fieldName : string

    欄位名稱（用於錯誤訊息顯示）。


    isCompleted : bool

    元件是否初始化完成。


    isContinue : bool

    是否持續驗證所有規則（否則遇錯即停止）。


    isInitial : bool

    是否為初始狀態。


    manager : QtObject

    Validator 管理器。

    當設定時，會自動將此 Validators 註冊至 manager。


    message : string [read-only]

    錯誤訊息。

    自訂 custom 錯誤訊息（由 target 提供）。

    target 需實作：

    function validate_custom_message(fieldName, error)

    mode : int

    驗證模式，參考 ModeType。

    ConstantDescription
    Validator.ModeType.Aggressive主動模式：value/rules/actived 變動時立即驗證。
    Validator.ModeType.Passive被動模式：被動呼叫 validate() 時驗證。
    Validator.ModeType.Lazy延遲模式：在適當時機（如失焦）才驗證。

    preManager : QtObject

    前一個管理器。

    處理 manager 變更時，獎此驗證器從前一個 manager 中移除。


    required : bool [read-only]

    是否包含 required 規則。


    rules : string

    驗證規則字串，以 | 分隔（例如："required|min:3|max:10"）。


    target : QtObject

    綁定的目標元件。


    value : var

    待驗證的值。
