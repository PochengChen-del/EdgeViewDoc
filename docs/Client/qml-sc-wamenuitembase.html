    Detailed Description

    WAMenuItemBase

    為 WAMenuItem 的基礎元件。 負責處理狀態管理、主題樣式（Theme）、尺寸與外觀邏輯。

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 多種選取樣式顯示與控制（checkStyle）
    • submenu 展開狀態處理
    • 自訂內容項目（items）

    元件內建互動狀態：

    • normal
    • hover
    • active
    • disable
    • readonly

    各狀態會繼承對應的 base state（例如 normal → normalbase）， 並透過 themeStyle 套用背景、邊框與內容顏色等。

    Property Documentation

    activeBaseState : State [read-only]

    active 狀態基礎設定。由 active 繼承。


    activeState : State

    active 狀態設定（繼承 activebase）。


    actived : bool

    是否為 active。


    arrowColor : StateColor

    各狀態更多選項指示器（arrow）顏色設定。


    bgColor : StateColor

    各狀態背景顏色設定。


    bgCoverGradient : StateGradient

    各狀態背景漸層設定。


    checkStyle : enumeration

    選取樣式類型，控制 indicator 的顯示方式。

    ConstantDescription
    WAMenuItemBase.CheckStyle.Check使用勾選圖示。
    WAMenuItemBase.CheckStyle.Switch使用開關樣式。
    WAMenuItemBase.CheckStyle.Checkbox使用 Checkbox 樣式。

    disableBaseState : State [read-only]

    disable 狀態基礎設定。由 disable 繼承。


    disableState : State

    disable 狀態設定（繼承 disablebase）。


    hasSubMenu : bool [read-only]

    是否有子菜單。


    hoverBaseState : State [read-only]

    hover 狀態基礎設定。由 hover 繼承。


    hoverState : State

    hover 狀態設定（繼承 hoverbase）。


    indicatorColor : StateColor

    各狀態選取指示器（indicator）顏色設定。


    isCheckboxStyle : bool [read-only]

    是否為 Checkbox 選取樣式。


    isSwitchStyle : bool [read-only]

    是否為開關選取樣式。


    items : Item

    子元件列表。


    normalBaseState : State [read-only]

    normal 狀態基礎設定。由 normal 繼承。


    normalState : State

    normal 狀態設定（繼承 normalbase）。


    padIndicator : bool

    是否保留 indicator 區域寬度。

    啟用後即使未顯示 indicator，仍會保留對應空間，用於維持多個 MenuItem 的對齊。


    readOnly : bool

    是否唯讀。


    readonlyBaseState : State [read-only]

    readonly 狀態基礎設定。由 readonly 繼承。


    readonlyState : State

    readonly 狀態設定（繼承 readonlybase）。


    selected : bool [read-only]

    是否為選取狀態。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。
