    Detailed Description

    提供顯示選項清單。

    支援功能：

    • 系統主題切換（systemThemeName）
    • 文字顯示（textRole, descRole）
    • 圖示顯示
    • 分組控制
    • 選取控制

    Property Documentation

    availableWidth : real [read-only]

    可用顯示寬度（扣除 leftPadding 與 rightPadding）。


    currentIndexes : var [read-only]

    目前已選取的 index 陣列。


    currentIndexesUnited : string

    目前選擇的 index 集合（以 "," 串接）。

    使用 string 組合，減少 changed 觸發的頻率。


    currentValues : var [read-only]

    目前已選取的 value 陣列。


    defaultExpanded : bool

    分組預設展開狀態。

    • true → 展開
    • false → 收合

    descElide : enumeration

    描述文字省略模式。


    descFont : font

    描述文字字型。


    descLineHeight : real

    描述文字行高。


    descMaxLineCount : int

    描述文字最大行數限制。

    當 textWrapMode 允許多行時，此屬性用來限制最多顯示行數。設為 0 表示不限制行數。


    descRole : string

    描述欄位 key。用於從 model object 中取得描述文字的 key。

    預設 "desc"。


    descWrapMode : enumeration

    描述文字換行模式。


    isArray : bool [read-only]

    判斷目前 model 是否為 Array 型態。


    lastOptionFullDiv : bool

    是否將最後一個選項的分隔線延伸至全寬。

    • true → 最後一個 item divider 使用 full width
    • false → 與一般 item 對齊 padding

    leftPadding : real

    左側邊距，整體左側縮排距離。


    optionBottomPadding : real

    選項下方邊距。


    optionLeftPadding : real

    選項左方邊距。


    optionRightPadding : real

    選項上方邊距。


    optionTopPadding : real

    選項上方邊距。


    rightPadding : real

    右側邊距，整體右側縮排距離。


    sectionRole : string

    分組欄位 key，用於從 model object 中取得分組文字的 key。


    selectAllText : string

    全選選項顯示文字。


    selectedStatus : var [read-only]

    選取狀態統計資訊（含全選 / 部分選取 / 分組統計）。

    回傳結構：

    {
    any: 是否有任一選取,
    all: 是否全部選取,
    count: 已選數量,
    total: 總項目數,
    sections: 分組統計（若 useSection = true）
}

    showDesc : bool

    是否顯示描述。


    showSelectAll : bool

    是否顯示全選選項。


    textElide : enumeration

    文字省略模式。


    textFont : font

    文字字型。


    textLineHeight : real

    文字行高。


    textMaxLineCount : int

    文字最大行數限制。

    當 textWrapMode 允許多行時，此屬性用來限制最多顯示行數。設為 0 表示不限制行數。


    textRole : string

    顯示文字欄位名稱。

    預設 "text"。


    textWrapMode : enumeration

    文字換行模式。


    useSection : bool [read-only]

    是否啟用分組。


    valueRole : string

    選項值欄位名稱。

    預設 "value"。
