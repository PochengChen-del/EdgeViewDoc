    Detailed Description

    提供頁面框架。

    元件組成：

    • Header：標題列、麵包屑、返回與操作/功能按鈕
    • Sidebar：側邊欄
    • Page：頁面內容

    支援功能：

    • 主題樣式控制（themeName）
    • 側邊欄控制
    • 操作/功能按鈕顯示（actions, buttons）
    • 自訂頁面內容（pageContent）
    • 自訂側邊欄內容（sidebarItem）

    使用：

    PageLayout {
    anchors.fill: parent
    pageContent: Item {
        anchors.fill: parent
    }
}
