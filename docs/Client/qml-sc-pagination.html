    Detailed Description

    提供頁碼顯示與前後頁切換控制，用於列表或資料分頁

    UI。

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 頁碼顯示（currentPage, total）
    • 頁碼切換控制

    Property Documentation

    currentPage : int

    目前頁碼。範圍為 1 ~ totalPage，超出範圍會自動修正。

    預設 1。


    radius : real

    按鈕圓角半徑。

    預設 4。


    totalPage : int [required]

    總頁數。

    注意：必須大於等於 1。
