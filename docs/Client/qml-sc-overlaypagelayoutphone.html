    Detailed Description

    提供頁面框架。

    元件組成：

    • Top Bar：頂部工具列
    • Header：標題列與返回按鈕
    • Page：頁面內容

    支援功能：

    • 主題樣式控制（themeName）
    • 自訂 TopBar 左右功能區塊（leftTopBarItems、l rightTopBarItems）
    • 自訂頁面內容（pageContent）

    使用：

    OverlayPageLayoutPhone {
    anchors.fill: parent
    pageContent: Item {
        anchors.fill: parent
    }
}

    當隱藏 TopBar 時，會取代 MainLayoutPhone 的 title。

    上方安全邊界。
