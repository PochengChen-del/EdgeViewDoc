    Detailed Description

    提供顯示訊息、詳細內容與狀態的通知提示框。

    通知會自動由畫面右側滑入，並支援自動關閉與手動關閉。

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 通知狀態顯示（notifyType）
    • 訊息顯示（message）
    • 自動關閉控制（interval）
    • 詳細內容視窗控制（detail）

    Property Documentation

    colorInverse : bool

    是否反轉顏色樣式。

    小尺寸模式預設為 true。


    detail : string

    詳細訊息內容。


    dlgDetail : QtObject

    詳細內容對話框物件，由 openDetail() 動態建立，關閉時自動銷毀。


    interval : int

    自動關閉時間（毫秒）。

    • > 0：通知開啟後會於指定時間自動關閉。
    • <= 0：不自動關閉。

    isError : bool [read-only]

    是否為 error 通知類型。


    isSuccess : bool [read-only]

    是否為 success 通知類型。


    isWarn : bool [read-only]

    是否為 warn 通知類型。


    maxWidth : real

    通知視窗最大寬度。


    message : string

    通知訊息內容。


    minWidth : real

    通知視窗最小寬度。

    預設 164。


    notifyType : string

    通知類型。

    • "info"
    • "success"
    • "warn"
    • "error"

    預設 "info"。


    rightGap : real

    通知視窗與右側邊界的間距。

    預設 24。


    showDetail : bool

    是否顯示詳細內容功能。

    當為 true 時，可透過詳細按鈕開啟詳細訊息視窗。


    showNotifyTypeArea : bool

    是否顯示通知類型顏色區塊。

    小尺寸預設不顯示。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。


    title : string

    通知標題文字。


    Method Documentation

    object getThemeStyle()

    取得主題樣式設定物件。

    \return主題樣式設定物件。


    openDetail()

    開啟詳細內容視窗。

    若 detail 存在，會建立並顯示詳細訊息對話框。

    開啟詳細視窗期間，自動關閉計時器會暫停，關閉後自動恢復。
