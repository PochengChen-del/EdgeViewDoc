    Detailed Description

    InputCombo

    作為 輸入元件（例如 WATextField） 的容器，負責排列子元件並提供組合顯示所需的資訊（例如數量與位置）。

    子元件可透過 isCombo 與相關屬性，自動調整圓角與邊界重疊行為。

    Property Documentation

    averageWidth : real [read-only]

    可見子元件在組合元件中可用的平均寬度。

    用於等分子元件寬度。


    childrenData : var [read-only]

    統計子元件數量與可見數量。


    count : int [read-only]

    子元件數量。


    isCombo : bool [read-only]

    表示此元件為組合容器。

    子輸入元件可透過此屬性判斷是否處於組合模式， 以調整圓角與邊界行為。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    visibleCount : int [read-only]

    可見子元件數量。

    用於子輸入元件判斷是否為單一顯示， 例如控制圓角是否完整顯示。
