    Detailed Description

    提供行動裝置搜尋頁面框架。

    搜尋邏輯需由外部覆寫 search() 進行實作。

    元件組成：

    • Header：返回按鈕、搜尋輸入框與清除按鈕
    • Page：搜尋結果區域

    支援功能：

    • 主題樣式控制（themeName）
    • 搜尋控制（searchText, search()）

    使用：

    SearchLayout {
    anchors.fill: parent
    pageItem: Item {
        anchors.fill: parent
    }

    function search() {
        // 實作搜尋
    }
}

    主題名稱。
