    Detailed Description

    提供複合型對話框元件，包含主內容區（Dialog）與側邊欄（Sidebar）。

    元件組成：

    • Dialog：主內容區
      • Header：標題列與操作區
      • Body：主體內容
      • Footer：底部操作區
    • Sidebar：側邊欄

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 大小控制
    • 側邊欄控制

    描述文字。


    descriptElide : enumeration

    描述文字省略模式。


    descriptMaximumLineCount : int

    描述文字最大行數限制。

    當 textWrapMode 允許多行時，此屬性用來限制最多顯示行數。設為 0 表示不限制行數。

    描述文字換行模式。

    尺寸類型，控制顯示的大小。
