    Detailed Description

    提供階層式導覽列項目，支援圖示、步驟編號、收折功能與多層級縮排。

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 文字顯示（text）
    • 圖示顯示（iconSourceUrl）
    • 步驟顯示（step）
    • 多層級縮排控制（level）
    • 收折/展開控制（expanded）

    元件內建互動狀態：

    • normal
    • hover
    • active
    • disable

    各狀態會繼承對應的 base state（例如 normal → normalbase）， 並透過 themeStyle 套用背景、邊框與內容顏色等。

    樣式由 style 決定。

    active 狀態基礎設定。由 active 繼承。


    activeState : State

    active 狀態設定（繼承 activebase）。


    actived : bool

    是否為 active。

    預設綁定 pressed。


    bgColor : StateColor

    各狀態背景顏色設定。


    bgCoverGradient : StateGradient

    各狀態背景漸層設定。


    disableBaseState : State [read-only]

    disable 狀態基礎設定。由 disable 繼承。


    disableState : State

    disable 狀態設定（繼承 disablebase）。


    divColor : StateColor

    各狀態 Divider 顏色設定。


    expanded : bool

    是否為展開狀態。


    hoverBaseState : State [read-only]

    hover 狀態基礎設定。由 hover 繼承。


    hoverState : State

    hover 狀態設定（繼承 hoverbase）。


    iconColor : StateColor

    各狀態圖示顏色設定。


    iconSourceUrl : url

    圖示來源 URL。

    當 style 為 Define.NavStyle.Icon 時使用。

    詳細格式與限制請參考 Qt 官方文件。

    暫時使用 string 型別。


    isIcon : bool [read-only]

    是否為圖示模式。


    isStep : bool [read-only]

    是否為步驟模式。


    level : int

    導覽階層層級，控制左側縮排與階層線顯示。


    nextPadding : real [read-only]

    下一層級縮排距離。


    normalBaseState : State [read-only]

    normal 狀態基礎設定。由 normal 繼承。


    normalState : State

    normal 狀態設定（繼承 normalbase）。


    notified : bool

    是否顯示通知提示。

    啟用後會於圖示右上角顯示提示點。


    showFold : bool

    是否顯示收折按鈕。


    showText : bool

    是否顯示文字內容。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    step : int

    步驟編號。

    當 style 為 Define.NavStyle.Step 時顯示。


    stepTextColor : StateColor

    各狀態 顏色設定。


    style : enumeration

    導覽項目樣式。

    預設 Define.NavStyle.None。

    ConstantDescription
    Define.NavStyle.None無樣式。
    Define.NavStyle.Step步驟樣式。
    Define.NavStyle.Icon圖示樣式。

    textColor : StateColor

    各狀態文字顏色設定。


    textElide : enumeration

    文字省略模式。


    textMaxLineCount : int

    文字最大行數限制。

    當 textWrapMode 允許多行時，此屬性用來限制最多顯示行數。設為 0 表示不限制行數。


    textWrapMode : enumeration

    文字換行模式。


    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。
