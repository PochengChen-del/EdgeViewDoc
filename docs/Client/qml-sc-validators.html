    Detailed Description

    用於集中管理多個驗證器（l

    validators）的驗證結果，並提供批次驗證功能。

    支援功能：

    • 聚合多個驗證器
    • 批次驗證（validateAll）
    • Validator 整合管理（manager）

    Property Documentation

    error : bool [read-only]

    是否存在任一驗證錯誤。


    manager : QtObject

    Validator 管理器。

    當設定時，會自動將此 Validators 註冊至 manager。


    preManager : QtObject

    前一個管理器。

    處理 manager 變更時，獎此驗證器從前一個 manager 中移除。


    target : QtObject

    綁定的目標元件。通常為表單容器或資料來源。


    validators : var

    驗證器列表。

    元素可以為：

    • Validator
    • Validators（巢狀）

    Method Documentation

    void add(QtObject vldr)

    新增驗證器。

    vldr Validator 或 Validators


    void remove(QtObject vldr)

    移除驗證器。

    vldr 要移除的驗證器


    validateAll()

    執行所有驗證器的驗證。

    若子項包含：

    • validateAll() → 遞迴呼叫
    • validate() → 單次驗證

    所有驗證會以 Promise.all 並行執行。

    \returnPromise，resolve 為：

    • true：全部通過
    • false：任一失敗
