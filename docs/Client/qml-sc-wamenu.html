    Detailed Description

    WAMenu

    為 Menu 的擴充元件，提供符合系統樣式的彈出式菜單。

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • MenuItem 顯示與控制（delegate）

    Property Documentation

    checkStyle : enumeration

    選取樣式類型，控制作為子項目時 indicator 的顯示方式。

    ConstantDescription
    WAMenuItemBase.CheckStyle.Check使用勾選圖示。
    WAMenuItemBase.CheckStyle.Switch使用開關樣式。
    WAMenuItemBase.CheckStyle.Checkbox使用 Checkbox 樣式。

    checkable : bool

    是否可勾選。

    啟用後可搭配 checked 與 checkStyle 使用。


    checked : bool

    目前是否為選取狀態。


    customBarItem : Component

    自訂 MenuBar 項目元件。

    可用於覆寫預設 MenuBar 顯示內容。


    description : string

    描述文字。


    iconSourceUrl : string

    圖示來源 URL。


    maxWidth : real

    菜單最大寬度。


    menuBarItemEnable : bool

    是否啟用 MenuBar 項目。


    minWidth : real

    菜單最小寬度。


    padIcon : bool

    是否保留圖示區域寬度。

    啟用後即使未顯示圖示，仍會保留對應空間，用於維持多個 MenuItem 的對齊。


    padIndicator : bool

    是否保留圖示區域寬度。

    啟用後即使未顯示圖示，仍會保留對應空間，用於維持多個 MenuItem 的對齊。


    show : bool

    是否顯示此選單。

    作為子選單時，可控制是否顯示於父選單中。


    showDescription : bool

    是否顯示描述。


    showIcon : bool

    是否顯示圖示。


    showSuffix : bool

    是否顯示後綴文字。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    suffix : string

    後綴文字。


    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。
