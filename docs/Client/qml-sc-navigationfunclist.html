    Detailed Description

    提供樹狀階層導覽功能，支援多層導覽項目、自動展開與路徑選取。

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 階層式導覽
    • 非同步選取檢查（checkBeforeSelectFunc）
    • 自訂文字與狀態邏輯

    Property Documentation

    bottomSafeMargins : real

    下方安全邊距。


    count : int [read-only]

    根節點數量。


    currentValues : var

    目前選取的導覽路徑。

    型態為 Array。


    isArray : bool [read-only]

    判斷目前 model 是否為 Array 型態。


    leftSafeMargins : real

    左側安全邊距。


    model : var

    導覽資料來源。

    每個項目需包含：

    • value
    • style
    • text（選用）
    • nextNavs（選用）
    • iconSource（選用）

    nextNavsRole : string

    子導覽資料欄位名稱。

    預設 "nextNavs"。


    rightSafeMargins : real

    右側安全邊距。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    styleRole : string

    顯示樣式欄位名稱。

    預設 "style"。


    textRole : string

    顯示文字欄位名稱。

    預設 "text"。


    topSafeMargins : real

    上方安全邊距。


    valueRole : string

    導覽值欄位名稱。

    預設 "value"。


    Method Documentation

    Promise checkBeforeSelectFunc()

    選取前檢查函式。

    可覆寫。

    string i18nText(object navData, array values)

    取得導覽項目顯示文字（優先 textRole，其次 valueRole）。

    可覆寫。


    bool navEnabled(object navData, array values)

    取得導覽項目是否啟用。

    可覆寫。


    bool navNotified(object navData, array values)

    取得導覽項目是否顯示通知提示。

    可覆寫。


    bool navVisible(object navData, array values)

    取得導覽項目是否顯示。

    可覆寫。


    void selectFirstFunc()

    選取第一個根導覽項目。

    若存在子節點，會自動遞迴選取第一個子項目。


    void selectFunc(array values)

    依據指定路徑選取導覽項目。

    values 導覽路徑陣列。

    若路徑不存在，currentValues 會被清空。
