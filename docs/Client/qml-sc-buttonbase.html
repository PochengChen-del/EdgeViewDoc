    Detailed Description

    ButtonBase

    是 Button 的基礎元件。 負責處理狀態管理、主題樣式（Theme）、尺寸與外觀邏輯。

    元件內建互動狀態：

    • normal
    • hover
    • active
    • disable

    各狀態會繼承對應的 base state（例如 normal → normalbase）， 並透過 themeStyle 套用背景、邊框與內容顏色等。

    樣式由 style、l colorType 與 contentColorType 決定。

    Property Documentation

    activeBaseState : State [read-only]

    active 狀態基礎設定。由 active 繼承。


    activeState : State

    active 狀態設定（繼承 activebase）。


    actived : bool

    是否為 active。

    預設綁定 pressed。


    bdColor : StateColor

    各狀態邊框顏色設定。


    bdWidth : StateReal

    各狀態邊框寬度設定。


    bgColor : StateColor

    各狀態背景顏色設定。


    bgCoverGradient : StateGradient

    各狀態背景漸層設定。


    colorType : enumeration

    背景顏色類型（由 WAColor 定義）。

    預設 WAColor.ColorType.Blue。


    contentColorType : enumeration

    內容顏色類型（文字或圖示）。

    對 Filled 樣式無效。

    預設 WAColor.ColorType.Gray。


    disableBaseState : State [read-only]

    disable 狀態基礎設定。由 disable 繼承。


    disableState : State

    disable 狀態設定（繼承 disablebase）。


    hoverBaseState : State [read-only]

    hover 狀態基礎設定。由 hover 繼承。


    hoverState : State

    hover 狀態設定（繼承 hoverbase）。


    inCombo : bool

    是否為組合按鈕的一部分。


    isFilled : bool [read-only]

    是否為填充樣式。


    isHyperlink : bool [read-only]

    是否為超連結樣式。


    isOutline : bool [read-only]

    是否為外框樣式。


    normalBaseState : State [read-only]

    normal 狀態基礎設定。由 normal 繼承。


    normalState : State

    normal 狀態設定（繼承 normalbase）。


    position : enumeration

    位於組合按鈕中的位置。

    預設 Define.ComboPosition.Center。

    ConstantDescription
    Define.ComboPosition.Left左側。
    Define.ComboPosition.Center中間。
    Define.ComboPosition.Right右側。

    radius : real

    按鈕圓角半徑。

    預設 4。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.ExtraSmall超小尺寸
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    style : enumeration

    按鈕樣式類型。

    預設 Define.ButtonStyle.Text。

    ConstantDescription
    Define.ButtonStyle.Outline外框樣式。
    Define.ButtonStyle.Text純文字樣式。
    Define.ButtonStyle.Filled填充樣式。
    Define.ButtonStyle.Hyperlink超連結樣式。

    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。
