    Detailed Description

    提供頁籤切換功能，用於多頁內容的導覽與切換。

    可透過 style 控制顯示風格，並依據 mode 切換一般頁籤或側邊欄樣式。

    背景與分隔線顏色由 themeStyle 提供。

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 風格與模式顯示（mode, style）

    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • false → Define.SizeType.Medium

    themeName : string

    主題樣式設定物件。
