    Detailed Description

    提供標準

    Dialog 結構。

    元件組成：

    • Header：標題列與操作區
    • Body：主體內容
    • Footer：底部操作區

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 顯示模式（style）
      • Center
      • Full
    • 大小控制

    Property Documentation

    bodyAvailableHeight : real [read-only]

    Body 可用高度（扣除 Header 與 Footer）。


    bodyAvailableWidth : real [read-only]

    Body 可用寬度。


    bodyItem : Item

    主體元件。

    Popup 主體內容（Body 區域），放置自訂 UI 元件，例如列表、表單、選擇器...。


    contentAvailableHeight : real [read-only]

    顯示可用高度 (扣除 minVertMargins)。


    contentAvailableWidth : real [read-only]

    顯示可用寬度 (扣除 minHorizMargins)。


    descript : string

    描述文字。


    descriptElide : enumeration

    描述文字省略模式。


    descriptMaximumLineCount : int

    描述文字最大行數限制。

    當 textWrapMode 允許多行時，此屬性用來限制最多顯示行數。設為 0 表示不限制行數。


    descriptWrapMode : enumeration

    描述文字換行模式。


    footerHeight : real [read-only]

    Footer height。


    footerImplicitWidth : real [read-only]

    Footer implicitWidth。


    headerHeight : real [read-only]

    Header height。


    headerImplicitWidth : real [read-only]

    Header implicitWidth。


    isFullStyle : bool [read-only]

    是否為 Full 模式。


    leftFooterItems : Item

    Footer 左方元件。


    leftHeaderItems : Item

    Header 左方元件。


    maxBodyHeight : real [read-only]

    Body 最大可用高度（扣除 Header 與 Footer）。


    maxContentHeight : real

    最大內容高度限制。


    maxContentWidth : real

    最大內容寬度限制。


    minBodyHeight : real [read-only]

    Body 最小可用高度（扣除 Header 與 Footer）。


    minContentHeight : real

    最小內容高度限制。


    minContentWidth : real

    最小內容寬度限制。


    minHorizMargins : real

    與邊界最小水平邊距。


    minMargins : real

    與邊界最小邊距。


    minVertMargins : real

    與邊界最小垂直邊距。


    radius : real

    圓角半徑。


    rightFooterItems : Item

    Footer 右方元件。


    rightHeaderItems : Item

    Header 右方元件。


    showClose : bool

    是否顯示關閉按鈕。


    showDescript : bool

    是否顯示描述。


    showFooter : bool

    是否顯示 Footer。


    showHeader : bool

    是否顯示 Header。


    showRequired : bool

    是否顯示必填。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設依據 Global.mobile 和 Global.tablet 決定：

    • true →
      • true → Define.SizeType.Small
      • false → Define.SizeType.ExtraSmall
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.ExtraSmall超小尺寸
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    style : enumeration

    設定顯示方式。 預設 WADialog1.Style.Center。

    ConstantDescription
    WADialog1.Style.Center顯示於中央。
    WADialog1.Style.Full顯示覆蓋整個視窗。

    themeName : string

    主題名稱。

    預設綁定 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。


    title : string

    標題文字。


    titleElide : Text.ElideMode

    標題截斷模式。


    titleWrapMode : Text.WrapMode

    標題換行模式。
