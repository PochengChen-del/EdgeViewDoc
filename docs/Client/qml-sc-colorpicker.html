    Detailed Description

    提供顏色選擇功能。

    元件組成：

    • Sliders：顏色選擇區（HSV與透明度）
    • Inputs：輸入區（顏色（HEX/RGB）與透明度輸入）
    • Brightness：明暗調整區
    • Palette：調色盤區（系統與自訂）

    支援功能：

    • 主題樣式控制（themeName）
    • 多尺寸顯示（sizeType）
    • 顏色選取與輸入處理
    • 顏色明暗處理
    • 自訂調色盤管理

    Property Documentation

    brightness : real

    亮度調整比例（0 ~ 1），控制「變亮/變暗」的強度。


    cellSpacing : real

    調色盤顏色項目間距。


    chipColumns : int

    調色盤顏色顯示欄數。


    color : color

    目前選擇的顏色。


    showBrightness : bool

    是否顯示亮度調整控制。


    showInputs : bool

    是否顯示 HEX / RGB 輸入區。


    showPalettes : bool

    是否顯示調色盤區。


    sizeType : enumeration

    尺寸類型，控制顯示的大小。

    預設會從父元件繼承，若未提供則依據 Global.mobile 決定：

    • true → Define.SizeType.Small
    • false → Define.SizeType.Medium
    ConstantDescription
    Define.SizeType.Small小尺寸
    Define.SizeType.Medium中尺寸

    sliderHeight : real

    顏色選擇區（HSV 與 Alpha）高度。


    themeName : string

    主題名稱。

    預設會從父元件繼承，若未提供則使用 WATheme.systemThemeName。


    themeStyle : var [read-only]

    主題樣式設定物件。

    此屬性為唯讀，透過 getThemeStyle() 動態產生。
